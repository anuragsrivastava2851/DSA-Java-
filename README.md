# DSA-Java

A collection of Data Structures and Algorithms (DSA) implementations and problem solutions in Java, built while practicing core DSA concepts.

## Contents

- **Queue** – queue implementations and problems (e.g. interleaving two halves of a queue)
- **array_list** – ArrayList-based problems (e.g. pair sum in a rotated ArrayList)
- **array_problem** – array-based problems
- **linked_list** – linked list implementation, including cycle removal and add operations
- **pattern_printing** – pattern printing programs (Butterfly Pattern, Diamond Pattern, etc.)
- **recursion** – recursion-based problems (e.g. printing binary strings of length n)
- **string** – string problems (insertion sort, duplicate elements, etc.)
- **binary_toDecimal.java** – binary to decimal conversion
- **decimal_toBinary.java** – decimal to binary conversion

## Tech Stack

- Java

## Purpose

This repo is a running log of DSA practice — implementations and solutions are added as new topics and problems are covered.
